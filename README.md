# FazliyevTLBBC2026 - Сборник задач по Python

Этот репозиторий содержит решения домашних заданий и лабораторных работ по программированию на языке Python. Проект организован по папкам в соответствии с номерами заданий.

## 📂 Структура проекта

*   **ДЗ_1** 
    *   `1.py` — Простой калькулятор (сложение, вычитание, умножение, деление).
    *   `2.py` — Калькулятор через функции (сложение, вычитание, умножение, деление).
    *   `3.py` — Бесконечный калькулятор через while True (сложение, вычитание, умножение, деление).
    *   `4.py` — Калькулятор через метод class (сложение, вычитание, умножение, деление).
*   **ДЗ_2** 
    *   `lines.py` — Работа со строками (5 уровней)
*   **ДЗ_3** 
    *   `labirint.py` — Игра - Лабиринт
